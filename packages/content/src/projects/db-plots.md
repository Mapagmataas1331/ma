Users pick channels and an interval, compare values on Plotly charts, and read channel reference data. The frontend uses React, TypeScript, Redux Toolkit, and a typed API layer. Dates and time zones are handled explicitly, and the build is published under an Nginx subpath.

<!-- ru -->

Пользователь выбирает каналы и интервал, сравнивает значения на графиках Plotly и смотрит справочные данные канала. Фронтенд на React, TypeScript и Redux Toolkit, со типизированным слоем API. Даты и часовые пояса заданы явно, сборка публикуется в подкаталоге Nginx.
